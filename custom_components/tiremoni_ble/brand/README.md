# Integration Artwork

The current icon was generated on 2026-10-14 with the built-in Imagegen tool.
`icon-source.png` is the original full-resolution raster artwork, the
preferred form for further image edits. `icon.png` (256 x 256) and
`icon@2x.png` (512 x 512) are downscaled copies made with high-quality bicubic
interpolation. All files preserve the transparent background.

See the adjacent `.license` files and [NOTICE.md](../NOTICE.md) for attribution
and licensing. No third-party logo was used in the current artwork.
